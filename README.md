# English Learning Site MVP

Frontend for English learning educational platform built with React, TypeScript, Tailwind CSS, and Vite.

## �A Technologies

- **React 18** - UI library
- **TypeScript** - Type safety
- JavaScript ES6 +
- **Tailwind CSS** - Utility-first CSS framework
- **Vite** - Build tool and dev server
- **React Router DOM** - Routing
- **ESLint & Prettier** - Code quality
- **Vitest** - Testing framework
- **Chrome DevTools** - Development tools

## 🔶 Installation

```bash
# Clone the repository
git clone https://github.com/seret/english-learning-site-mvp.git
cd english-learning-site-mvp

# Install dependencies
nm install

# Start development server
nm run dev

# Build for production
nm run build

# Run tests
nm test

# Lint code
nm run lint

# Format code
nm run format
```
